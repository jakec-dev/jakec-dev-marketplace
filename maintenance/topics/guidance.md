# Guidance topics

- `discover.md`: deciding what in a repository or a way of working deserves a Claude tool, and what does not
- `choose.md`: picking the kind of Claude tool that fits a goal
- `write.md`: writing the content of CLAUDE.md files and rules so that Claude follows it
- `compose.md`: making several tools work together within Claude's context
- `verify.md`: proving that a tool works before calling it done
- `maintain.md`: keeping existing tools useful, and finding the ones to cut
